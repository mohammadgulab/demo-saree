# Anaya Sarees (demo)

Demo website for a fictional saree shop in Varanasi. Shop by colour cards, a hanging collection rail with filters, scroll zoom, open now badge, English and Hindi, and a booking form that writes the WhatsApp message.

Live: https://mohammadgulab.github.io/demo-saree/

Design and code by Mohammad Gulab. Photos from Wikimedia Commons, credited in the page footer.
